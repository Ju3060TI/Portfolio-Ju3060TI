Custom Inference Engine & Sparse Mixture-of-Experts Architecture

A ground-up inference engine built in Rust around a proprietary Sparse Mixture-of-Experts (SMoE) architecture. Designed for local execution on consumer hardware — no cloud, no external APIs.

Architecture

  • Custom SMoE routing with dynamic token-level gating
  • Activates exactly 55B parameters per inference step — no wasted compute
  • Zero-copy shared memory IPC protocol targeting sub-5ms latency between agents
  • Purpose-built for multi-agent workloads (pathfinding, tactical decision systems)

Implementation

  • Native Rust core with custom CUDA kernels via Rust FFI
  • Direct control over memory layout and scheduling — no framework overhead
  • Designed from the ground up for deterministic latency under load

3D Voxel & Automation Engine

A high-performance custom voxel engine written in C# and Vulkan. Built for infinite worlds that combine sandbox building, factory automation and survival-scale simulation in a single runtime.

Architecture

  • Infinite terrain generated in RAM-lean form via closed-form fractal functions
  • Hybrid delta-storage system — only modified blocks are persisted, everything else stays procedural
  • Heap-allocation-free render loop for stable frame times at scale
  • Targets millions of simultaneously moving parts without frame drops

Implementation

  • Custom Vulkan renderer with chunked GLSL shaders
  • Deterministic world state: identical coordinates always produce identical terrain
  • Engineering scope spans Minecraft-style voxels, Satisfactory-tier automation, 7DTD-scale persistence

Stack

  • C#
  • GLSL
  • Vulkan
  • Procedural Generation

Mörser-Karl GX

Live

Isolated Browser-in-Browser Web Environment

A browser-inside-the-browser experience, built entirely as a web application. Simulates its own isolated shell on top of the existing browser, giving private web apps a closed environment that never touches the open internet.

Architecture

  • Custom chrome, navigation and app shell built from scratch on top of the browser runtime
  • Fake error screen serves as an Access Shield Gateway — a deliberate misdirection layer that hides authenticated apps behind a plausible dead end
  • Sandboxed app surface: only whitelisted internal apps are reachable
  • No outbound traffic to the regular web — access to external sites is disabled by design

Implementation

  • Vanilla HTML, CSS and JavaScript — no framework dependencies
  • Acts as the sole runtime host for Flarechat and other internal apps
  • Session isolation: no shared storage, cookies or caches with the host browser

Stack

  • HTML
  • CSS
  • JavaScript
  • App Sandboxing

Stealth Chat Platform

A real-time messenger that runs natively inside the Mörser-Karl GX browser-in-browser environment. Built purely on web primitives — no backend framework, no external services.

Architecture

  • Friend system based on short 6-digit identifiers
  • Group chats with role handling
  • Stealth Mode — instantly hides the interface behind an inconspicuous decoy view

Implementation

  • Zero-config deployment: no external URLs, no CDN calls, no third-party dependencies
