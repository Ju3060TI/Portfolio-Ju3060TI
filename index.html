NERON AI

Local inference engine

NERON is a fully local inference engine built around a 22B parameter sparse mixture-of-experts architecture. It runs entirely on a single consumer GPU without any cloud dependency.

What it does

Multiple specialized agents run in parallel and route requests through a shared memory bus. The entire pipeline stays on-device — no network calls, no external APIs.

Technical highlights

  • Zero-copy shared memory IPC between agents
  • Sub-4ms latency per inference step
  • Sparse routing to keep VRAM usage low
  • Written from scratch in Rust with custom CUDA kernels

Stack

  • Rust
  • CUDA
  • IPC
  • ONNX

MaJuTiKi: Blocks

3D voxel engine

A real-time voxel engine designed for infinite worlds. Terrain is generated procedurally on the fly with no loading screens and constant memory usage.

What it does

Worlds are computed from closed-form fractal functions, meaning the same coordinates always produce the same terrain — no storage needed, no loading.

Technical highlights

  • Closed-form fractal terrain generation
  • Heap-allocation-free render loop
  • Custom GLSL shaders for chunked rendering
  • Infinite world with no visible boundaries

Stack

  • C#
  • GLSL
  • Vulkan

Mörser-Karl GX

Custom web browser

A self-contained browser with its own shell, custom interface and a built-in access shield. Designed as a sandboxed environment for private web apps that shouldn't touch the regular web.

What it does

Everything runs inside an isolated shell. Only whitelisted apps are reachable — the regular internet stays out. Its own error page doubles as an access gate.

Technical highlights

  • Custom UI layer over WebView
  • Fake error page as access shield
  • Isolated session — no shared cookies with system browser
  • Hosts internal apps like Flarechat

Stack

  • C#
  • .NET
  • WebView
